================================================================================
MEDICAL WIZARD - SYSTEM EXECUTION & REVIEWER GUIDE
================================================================================

This document provides clear, step-by-step instructions to run the Medical
Wizard Clinical Operations Platform locally, along with credentials,
architecture details, and key features to test.

================================================================================
1. SYSTEM PREREQUISITES
================================================================================

Before starting, ensure you have the following installed on your machine:
  • Go:       Version 1.22 or higher (Check with: go version)
  • Node.js:  Version 18 or higher (Check with: node -v)
  • npm:      Version 9 or higher (Check with: npm -v)
  • (Optional) Docker & Docker Compose (if using a local PostgreSQL container)

================================================================================
2. STEP-BY-STEP EXECUTION GUIDE
================================================================================

The backend is pre-configured with a live Neon Serverless Cloud PostgreSQL
database (`DATABASE_URL` in `backend/.env`). No manual database installation
or SQL migration is required!

--------------------------------------------------------------------------------
STEP 1: START THE GO BACKEND SERVER (Port 8080)
--------------------------------------------------------------------------------
1. Open a terminal / command prompt.
2. Navigate to the backend directory:
     cd backend

3. (First time only) Download Go module dependencies:
     go mod tidy

4. Start the backend server:
     go run cmd/server/main.go

   Expected Output:
     - "Starting Medical Wizard Clinical Operations & RBAC API..."
     - "Successfully connected to Cloud PostgreSQL database (Neon)"
     - "Database migration, seeding, and RBAC provisioning completed successfully."
     - "Server listening on port :8080"

--------------------------------------------------------------------------------
STEP 2: START THE REACT FRONTEND (Port 5173)
--------------------------------------------------------------------------------
1. Open a second terminal / command prompt.
2. Navigate to the frontend directory:
     cd frontend

3. (First time only) Install frontend node dependencies:
     npm install

4. Start the Vite development server:
     npm run dev

   Expected Output:
     - "VITE v8.x.x ready in ... ms"
     - "➜  Local:   http://localhost:5173/"

5. Open your web browser and navigate to:
     http://localhost:5173

================================================================================
3. (OPTIONAL) RUNNING WITH LOCAL DOCKER POSTGRESQL
================================================================================

If you prefer running a local PostgreSQL database instead of the Cloud database:

1. In the project root, start PostgreSQL using Docker Compose:
     docker compose up -d

2. Update `backend/.env` to point to your local database:
     DATABASE_URL=postgres://postgres:postgres@localhost:5432/medwizard?sslmode=disable

3. Start the backend as described in Step 1. Tables and seed data will be
   automatically generated in your local database.

7. TROUBLESHOOTING & COMMON QUESTIONS
================================================================================

Q: Port 8080 or Port 5173 is already in use:
A: • To change backend port, set `PORT=8081` in `backend/.env`.
   • To change frontend port, run `npm run dev -- --port 5174` in `frontend/`.

Q: Database connection errors:
A: Ensure your machine has internet access to connect to Neon Cloud PostgreSQL.
   The connection string is pre-set in `backend/.env`.

Q: How to run backend unit tests?
A: In `backend/`, run:
     go test -v ./...
