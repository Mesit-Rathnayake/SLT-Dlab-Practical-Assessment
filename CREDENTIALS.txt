3. RUNNING LOCALLY
--------------------------------------------------------------------------------
Prerequisites: Go 1.22+, Node.js 18+, (Docker optional, Neon Cloud is default)

Backend:
  cd backend
  go run cmd/server/main.go
  (Listens on port 8080, connects to Neon Cloud DB automatically)

Frontend:
  cd frontend
  npm install
  npm run dev
  (Runs on http://localhost:5173)
