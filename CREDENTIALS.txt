3. PATIENT RECORDS & NIC (NATIONAL IDENTITY CARD) SYSTEM
--------------------------------------------------------------------------------
In accordance with hospital administrative security, patient records are managed
internally by clinical staff:
  - Unique Primary Identifier: National Identity Card (NIC) number.
  - Appointment Booking Workflow:
    1. Enter Patient NIC (e.g. 198810502341).
    2. System verifies NIC against database.
    3. If existing patient: displays previous consultation history and autofills demographics.
    4. If new patient: registers permanent patient record linked to that NIC.
    5. The booked appointment is automatically linked to the patient's chronological history.

4. LOCAL EXECUTION GUIDE
--------------------------------------------------------------------------------
Prerequisites: Go 1.22+, Node.js 18+

Backend:
  cd backend
  go run cmd/server/main.go
  (Listens on port 8080)

Frontend:
  cd frontend
  npm install
  npm run dev
  (Runs on http://localhost:5173)
